# Getting Started

Benvenuto nel sistema MD to WWW! Questo documento ti guida attraverso i primi passi.

## Introduzione

MD to WWW è un sistema general purpose che converte automaticamente file Markdown in un sito web funzionante. Basta aggiungere file `.md` nella cartella `MD_Contents/` e il sito si aggiorna automaticamente.

## Caratteristiche Principali

- **Hot Reload**: Le modifiche ai file vengono rilevate automaticamente
- **Syntax Highlighting**: Il codice viene evidenziato con colori
- **Tabelle**: Supporto completo per tabelle Markdown
- **Formattazione Personalizzabile**: Puoi cambiare font e dimensione del testo

## Prossimi Passi

1. Aggiungi i tuoi file Markdown in `MD_Contents/`
2. Ogni file deve iniziare con un titolo `# Titolo`
3. Il sistema estrae automaticamente il titolo per la navigazione
4. Usa il pannello di formattazione per personalizzare l'aspetto

Buon lavoro!
