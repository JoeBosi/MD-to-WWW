# MD_Contents

Questa cartella contiene tutti i file Markdown che vengono automaticamente convertiti in pagine web.

## Come Funziona

1. Aggiungi file `.md` in questa cartella
2. Ogni file deve iniziare con un titolo `# Titolo`
3. Il sistema estrae automaticamente il titolo per la navigazione
4. Le modifiche vengono rilevate automaticamente (hot reload)

## Convenzioni

- **Nomi file**: Usa nomi descrittivi con trattini (es: `getting-started.md`)
- **Titoli**: Ogni file deve iniziare con `# Titolo` come prima riga
- **Struttura**: Organizza il contenuto con heading appropriati

## Esempi

Vedi i file di esempio in questa cartella:
- `getting-started.md` - Guida introduttiva
- `examples.md` - Esempi di tutti i tipi di Markdown supportati
